# StartupMate AI - Startup Idea Assistant

## How to run
1. Install Python 3.9+
2. Open terminal in this folder and run:  pip install -r requirements.txt
3. Set your API key (get it from console.anthropic.com):
   - Windows:   set ANTHROPIC_API_KEY=your_key_here
   - Mac/Linux: export ANTHROPIC_API_KEY=your_key_here
4. Run:  python app.py
5. Open http://127.0.0.1:5000 in your browser
